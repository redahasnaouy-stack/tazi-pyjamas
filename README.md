# Tazi Pyjamas

Boutique de pyjamas en français, interface responsive rose, crème et bordeaux. Panier persistant, choix de taille, filtres, favoris, commandes WhatsApp au **0663266817**, paiement à la livraison. Dashboard privé `/admin` pour les demandes et leur suivi via Netlify Identity + Blobs.

```sh
npm ci
npm run dev
npm test
npm run build
```

Déploiement et réglages : [DEPLOYMENT.md](DEPLOYMENT.md). Trois premiers modèles de 250 à 320 DH ; les autres images du catalogue restent à intégrer après remplacement de leurs marques. Le backend se valide après déploiement Netlify.
