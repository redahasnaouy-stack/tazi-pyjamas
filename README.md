# Tazi Pyjamas

Boutique de pyjamas en français, interface responsive rose, crème et bordeaux. Panier persistant, choix de taille, filtres, favoris, commandes WhatsApp au **0663266817**, paiement à la livraison. Dashboard privé `/admin` pour les demandes et leur suivi via Netlify Identity + Blobs.

```sh
npm ci
npm run dev
npm test
npm run build
```

Déploiement et réglages : [DEPLOYMENT.md](DEPLOYMENT.md). Catalogue de 55 fiches regroupant les 83 photos fournies, avec galeries, filtres et affichage progressif. Les prix restent entre 200 et 350 DH. Les marques sont retirées des vêtements ; le logo Tazi est affiché séparément sur les visuels. Le backend se valide après déploiement Netlify.
